JULIO Financial Command Centre

JULIO is a personal, owner-operated application for reviewing financial-message records, generating and validating ISO 20022 XML, and tracking controlled message exchanges and an auditable ledger.

This is JULIO’s public information page. The application dashboard and its records require owner authentication.

Why JULIO requests Gmail access

The owner connects dad.built.digital@gmail.com so JULIO can send email verification codes and fixed identity notifications to that same address. Google consent is followed by a single-use code confirmation before JULIO records the primary email as verified.

JULIO requests Gmail sending permission and basic Google email identity. It does not request permission to read the Gmail inbox, contacts or Drive files. OAuth tokens remain on the application server; the dashboard does not receive them.
